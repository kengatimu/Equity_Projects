The last 3 digits of the credit-party-identifier will determine the response given and the "X" stands for any number. For example if a test number +44 0793 161 7100 is given, the response from our system will be "COMPLETED", and if a test number 272715678101 is given, the response will be "DECLINED-INVALID-BENEFICIARY".
