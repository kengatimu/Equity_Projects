22-Mar-2021

Swagger File Changes

1. Purp/Cd changed to Purp/Prtry – The tag wa altered from ISO defined codes to Proprietary to allow proprietary codes concerning payment purpose to be populated in the tag.
2. RmtInf/Ustrd description corrected to a more clearer field description.
3. Added SchmeNm/Prtry – This is a new field, added to distinguish account number from phone number stored under the same tag ./CdtrAcct/Id/Othr/Id;
4. Added /v1/credit-transfer-bulk endpoint for IPS swagger – this is meant to facilitate bulk credit transfer. Only one field (./GrpHdr/TtlIntrBkSttlmAmt) is different from the single credit transfer endpoint.
5. Added /v1/payment-status-report-bulk endpoint for Participant swagger - this is where IPS will send bulk payment status report. Four fields are different from single credit transfer status report:
./OrgnlGrpInfAndSts/OrgnlNbOfTxs
./OrgnlGrpInfAndSts/OrgnlCtrlSum
./OrgnlGrpInfAndSts/GrpSts
./OrgnlGrpInfAndSts/StsRsnInf

6. Removed TtlIntrBkSttlmAmt from /v1/credit-transfer endpoint and transferred it to bulk credit transfer endpoint.
7. Changed importance for all <Cdtr> details in pacs.008 to optional 
8. Changed importance for ./CtctDtls/PhneNb> (except pacs.008 cdtr) to mandatory
9. Change importance for <DtAndPlcOfBirth> to optional – requested by Lucy
10. Extended IPS swagger endpoints with /iso20022/ - applies only for IPS swagger. This was added to avoid ambiguity from IPSL side. All IPS endpoints now start with: /iso20022/. For example credit transfer endpoint would become: https://api.start.ipsl.co.ke/iso20022/v1/credit-transfer
