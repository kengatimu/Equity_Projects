ACCOUNT VERIFICATION FLOW

Assuming you are sending a request from Prime Bank to Prime Bank (0010);

1. You send a verification request to: 

"https://api.start.ipsl.co.ke/iso20022/sync/v1/verification-request" - waiting request

2. IPS sends the verification request to your (beneficiary) verification endpoint:

"https://cpfw01.creditbank.co.ke:8443/CreditBank_IPSL/v1/verification-request"

3. You (acting as beneficiary) responds back with acmt.024 to:

"https://api.start.ipsl.co.ke/iso20022/sync/v1/verification-report"

4. IPS responds back to the waiting request in step 1 above
